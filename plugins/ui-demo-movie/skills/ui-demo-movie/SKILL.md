# 実演動画を作る（ui-demo-movie）

**完成した実画面のスクショ1枚（または空の画面＋完成の画面の2枚）があれば、「AIが動いている動画」は作れる。**
やることは「出来上がった画面を、いったん消して、順に出し直す」だけ。映っている文字・金額・ファイル名は実画面のままなので、作り物に見えない。

- 出力：1920x1080・30fps・無音・H.264（15〜20秒が目安。スライドに貼って自動再生）
- 必要なもの：Python 3（Pillow・numpy）、ffmpeg
  - Mac `brew install ffmpeg`／Windows `winget install ffmpeg`／どちらでも `pip install imageio-ffmpeg` で可
  - 日本語フォントは自動で探す（Mac＝ヒラギノ／Windows＝游ゴシック・メイリオ）。見つからなければ環境変数 `UIDEMO_FONT` にパス
- 動作確認：`python scripts/example_build.py` → `scripts/example_out/example.mp4`（架空データで約15秒）

## まず決めること＝「渡すもの → 記帳されたもの」

通る形はこれだけ。**画面は「AIに渡すもの」と「AIが書き込んだ先」の2つ**。AIの姿は、**書き込み中の行の行番号を赤い「AI」チップに差し替えて、行を赤線で挟む**ことで見せる。

| 業務 | 渡すもの（入口） | 記帳されたもの（出口） | 最後の一押し |
|---|---|---|---|
| 勤怠 | 打刻ログ160行が流れる（ScrollScene） | 集計表に1人ずつ書き込まれる（FillScene） | 残業45時間超の人が赤枠で出る（alerts） |
| 名刺 | 名刺の写真（SideBySide の左） | 顧客リストに1行ずつ（FillScene） | 残りの名刺が積まれて行が埋まる（speedup） |
| 経費 | レシートの写真・ドライブ一覧 | 仕訳帳（FillScene） | — |
| 請求書 | 請求予定の台帳（FillScene） | メール文面が打たれ添付が付く（TypingScene）→下書きが積まれる（StackScene） | 人が送信を押す（ClickScene） |
| 社内ヘルプ | — | 実際のチャットで質問→即回答が続く（ChatScene） | — |

**しょぼさは「量」で潰す。** 5行の表は「これくらい手でできる」に見える。打刻ログ160行・名刺29枚・下書き10通のように、人がやったら面倒な量にする。

## やらないこと（セミナー投影で6回差し戻されて分かったこと）

| やりがちなこと | 言われたこと | なぜダメか |
|---|---|---|
| 長い字幕・説明文を付ける | 「微妙かも」 | **話し手の声と二重になる**。字幕は上の灰色ラベル1行だけ（何をしている場面か） |
| Before/After を図やチップ表（人／AI）で説明する | 「四角で示すやり方も微妙」 | 説明であって実演ではない。**動きで見せる** |
| 実画面を3枚並べて切り替えるだけ | 「スクショのスライドショーにしか見えない」 | AIが動いていない。セルが埋まる・文字が打たれる・ボタンが押される、まで動かす |
| 何本も同じ演出を当てる | 「なんか全部同じに見えるね」 | 素材が全部スプレッドシートだと差が消える。**入口（写真・ログ・チャット）を変えて差を付ける** |
| カメラの寄り・引き・パン、タブ切り替え | 「カメラの変化で誤魔化すのやめてみよう」 | 中身が変わっていない |
| ChatGPT等の画面に社員データを貼る様子を撮る | 「データを外部AIに渡していいのか」「このくらいならできる」 | 見る人が内容より先にセキュリティを考える。しかもしょぼく見える |
| 自作のチャット画面・自作UIで撮る | 「作り物にしか見えない」「何やってるかわかりづらい」 | **画面は実物を撮る**。チャットなら本物のSlack等に架空の資料を置いて、実際に質問して撮る |

## 手順

### 1. 架空データで実画面を作る
- 本物のスプレッドシート／Gmail／ドライブ／Slackに、**架空のデータ**を入れる。実在の取引先・個人情報は使わない
- 架空にするときのルール：会社名は「サンプル◯◯」等、メールは `@example.com`、電話は局番 `000`、住所は「サンプル町」
- **実在企業のレシート・請求書を偽造しない**（店名も架空にする）
- **数字は合計だけでなく1行ずつ検算する**。合計が合っていても「残業 −3.5時間」のような変な行が混じる。作るスクリプトに `assert` を入れる

### 2. 撮る
- 表は **「空の状態」と「全部入った状態」の2枚** を、**同じ位置・同じ拡大率・同じウィンドウサイズ** で撮る（差分で位置を取るため）。ブラウザの拡大（約200%）で撮ると文字が潰れない
- 縦に長い画面（ログ・チャット）はスクロールしながら複数枚撮って縦に貼り合わせる
- メール等は「完成した状態」を1枚

### 3. 座標を画素から取る（🔴目で読まない）
スクショにルーラーを重ねて目で読むと、**行が2/3行ずれる・列が200pxずれる**（実際に2回続けて外した）。必ず `scripts/measure.py` で取る。

```
python scripts/measure.py diff  empty.png full.png        # 表：データが入った行の帯 → row_top / row_h / n_rows
python scripts/measure.py lines mail.png 300 1600 200 800 # 文面：文字が載っている行の (y0, y1)
python scripts/measure.py hlines sheet.png 400 1500       # 横罫線（見えるとき）
python scripts/measure.py bands list.png                  # 地の色の帯（一覧の行の区切り）
```
- Googleスプレッドシートの罫線は薄すぎて拾えない → **空と完成の差分**で行・セルを出す（FillScene が自動でやる）
- 背景色つきの行（ハイライト行）は隣とつながって2行が1行に見える → 行は**等間隔で切る**（row_top + i×row_h）
- 消す色は決め打ちせず、その場所の**最頻色**で塗る（`vlib.bg_of`）。白でも淡い黄色の行でも合う
- 消し残りが出たら、マスクを数px広げる（セル境界ぎりぎりの文字・添付の枠線が残りやすい）

### 4. 組み立てる
`scripts/example_build.py` をコピーして、素材を描く部分を「スクショを読み込む」に置き換える。

```python
import vlib, scenes
from PIL import Image
EMPTY = Image.open("empty.png").convert("RGB")
FULL  = Image.open("full.png").convert("RGB")
S = [
    scenes.ScrollScene(Image.open("log_tall.png").convert("RGB"), "これまで：この160行を、人が数えていました"),
    scenes.FillScene(EMPTY, FULL, "AIが、人ごとに集計して書き込む",
                     row_top=239, row_h=26.0, n_rows=8, crop=(46, 20, 1664, 470), alerts=(2, 6)),
]
scenes.preview(S, "preview.png")   # ← 先にこれを見て、消える場所が合っているか確かめる
scenes.render(S, "demo.mp4")
```

| 部品 | 見せること | 主な引数 |
|---|---|---|
| `ScrollScene` | 量（ログが流れる） | 縦長画像・秒数 |
| `FillScene` | 表が1行ずつ埋まる＋赤い「AI」 | empty/full・row_top・row_h・n_rows・alerts・speedup |
| `TypingScene` | 文面が打たれる＋添付 | 行の (y0,y1) 一覧・x範囲・attach |
| `StackScene` | 一覧に積まれる（古い＝下から） | 行の (y0,y1) 一覧 |
| `ClickScene` | 人が送信を押す | カーソル開始位置・ボタンの枠・押した色 |
| `ChatScene` | 質問→即答が続く | 縦長スクショ・各メッセージの上端・出す時刻 |
| `SideBySide` | 左＝入口／右＝記帳先 を同時に | 2つの場面・左の幅の割合 |

テンポの目安：1行 0.5秒前後・セル間 0.05秒・1場面 4〜7秒・全体 15〜20秒。量が多いときは `speedup=1.1` 前後で後ろほど速く。

### 5. 確かめてから渡す
- `preview.png` で**消える場所が正しい行・列か**を見る（別の行を消していた事故あり）
- 書き出したMP4から数コマ抜いて見る：`ffmpeg -ss 5 -i demo.mp4 -frames:v 1 check.png`
- 架空データ以外（本物の社名・個人名・メールアドレス）が映り込んでいないか、端まで見る
- スライド（PowerPoint/Canva）に貼って、自動再生で頭から最後まで流す

## Gotchas
- 2枚の画像の大きさが違うと `measure.py diff` が止まる → 同じウィンドウサイズで撮り直す
- 静止画を ffmpeg の concat で並べると尺が狂うことがある → 本スキルは1コマずつ生で流し込むので起きない
- 絵文字は日本語フォントに無く豆腐（□）になる → ラベルに絵文字を使わない
- 件数表示（「1-6/6行」「下書き 6」など）と見えている行数が食い違う画面は、その表示が入らない位置で切り出す（`crop`）
